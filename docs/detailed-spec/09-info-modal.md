# 09 インフォメーションモーダルの文言

仕様書 §5.6・§10 の文言を、画面ごとの確定稿にしたもの。画面上に出さない説明・操作方法・記号の意味は、すべてここに集約する。
表示形式は「見出し（dt）＋本文（dd）」の定義リスト。モーダルのタイトルは画面名。閉じるボタンは「閉じる」。

仕様書 §10 の本文をそのまま使い、次の点だけ補った（補った箇所は【補】）。

- ログイン画面の項目（仕様書に画面の定義がないため）【Q-13】
- 色の見分け方（ICMCLEC 踏襲の配色にしたため）【Q-2】

## §1 スポット一覧（仕様書 §10.1）

| 見出し | 本文 |
|---|---|
| タブ | 「すべて」と「自分の投稿」。 |

## §2 レンジ入力（仕様書 §10.2）

| 見出し | 本文 |
|---|---|
| 視点 | Villain（あなた）の席から、Hero のアクションに対する Villain のレンジを入力する。 |
| リプレイ | スポットまでのアクションを再生する。Hero のハンドは回答後に公開される。 |
| ブラシ | 上部のアクションを押すとそのアクション 100% のブラシになる。バーの境界をドラッグすると混合戦略（5% 刻み）を作れる。マスをタップ、またはなぞるとブラシの頻度で塗られる。 |
| 色【補】 | 赤はフォールド、シアンはチェックとコール、黄はベットとレイズ。マスの中では左からフォールド、チェック、コール、ベット・レイズの順に並ぶ。 |
| スポイト | マスを長押しすると、そのマスの頻度をブラシに読み込む。 |
| レンジ外 | 塗らないマスはレンジ外（このスポットに到達しないハンド）。消しゴムで塗ったマスをレンジ外に戻せる。ブラシと同じ頻度のマスをもう一度押しても消える。 |
| 元に戻す・やり直す・クリア | 塗る操作を 1 回ずつ戻せる。なぞった操作は 1 回分として扱う。クリアで全マスをレンジ外に戻す。 |
| サイズ | 33%・50%・75%・125% はコール後のポットに対する割合。レイズの場合は現在のベット額にその分を足した額が to になる。入力欄とゲージで任意のサイズに調整できる。 |
| 下部のバー | 1326 combos に対する各アクションとレンジ外の比率。 |
| 送信 | 回答は 1 スポットにつき 1 回で、送信後は変更できない。自分の投稿への入力は Hero の予想として保存され、全体の集計には含まれない。Hero の予想は何度でも変更できる。 |

## §3 集計（仕様書 §10.3）

| 見出し | 本文 |
|---|---|
| 色 | マス内の色の割合がアクション頻度を表す（そのハンドをレンジ内とした回答者の平均）。赤はフォールド、シアンはチェックとコール、黄はベットとレイズ。【補：色の対応】 |
| 濃さ | そのハンドをレンジ内に含めた回答者の割合。薄いほどレンジ外とした回答者が多い。 |
| 白枠 | Villain の実際のハンド。ショーダウンがない、またはマックの場合は表示されない。 |
| 上部のバー | 1326 combos に対する各アクションとレンジ外の比率。レンジ内とした回答者の割合で重み付けしている。 |
| タブ | 全体・自分・Hero の予想を切り替えられる。マスを選ぶと内訳が表示される。 |
| ハンドヒストリー | ハンドを最後まで再生し、ショーダウンのハンドを確認できる。 |

## §4 スポット投稿（仕様書 §10.4）

| 見出し | 本文 |
|---|---|
| 画像読み込み | T4 のハンドヒストリー画像を端末内で OCR する。画像は読み取り後に削除され、保存も送信もされない。 |
| 基本設定 | キャッシュゲームではアンティとレーキを任意で入力する。MTT ではレーキは入力できない。アクション入力後は変更できない。 |
| プレイヤーとハンド | 分かっているハンドのみ入力する。Hero のハンドは必須。フォールドした席でも判明していれば入力できる。ハンド欄を押すとカードキーボードが表示される。 |
| カードキーボード | A キーはタップで A、押したまま上で K・右で Q・下で J・左で T。♠ キーはタップで ♠、上で ♥・右で ♦・下で ♣。1 → 0 で T。C で席のハンドをクリア、⌫ で 1 文字削除。使用済みのカードは入力できない。 |
| ショーダウン | ハンドが入力されていない席はマックとして扱う。 |
| アクション入力 | そのスポットで取れないアクションは非活性になる。ストリートが終わるとボード入力に進む。「1つ戻す」はアクションだけを戻し、ボードは残る。 |
| スポット | Hero のアクションを 1 つと Villain を 1 つ選ぶ。回答対象はその後の Villain の最初のアクション。フォールドした席も Villain に選べる。 |

## §5 アカウント（仕様書 §10.5）

アカウントメニューを開いている間に ⓘ を押した場合、または規約ページで ⓘ を押した場合に表示する。

| 見出し | 本文 |
|---|---|
| アカウント | 利用規約、プライバシーポリシー、ログアウト、アカウント削除（投稿・回答をすべて消す。元に戻せない）。 |
