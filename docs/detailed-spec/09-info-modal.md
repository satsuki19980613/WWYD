# 09 インフォメーションモーダルの文言

画面ごとの確定稿。画面上に出さない説明・操作方法・記号の意味は、すべてここに集約する。ポーカー用語は英語で書く（15 章）。
表示形式は「見出し（dt）＋本文（dd）」の定義リスト。モーダルのタイトルは画面名。閉じるボタンは「閉じる」。

**2026-09-29 さつき「情報が多すぎる。必要最小限で簡潔に」**: 画面を見れば分かること（タブ・絞り込み・ボタンの名前・再生の記号・遷移など）は書かず、
見て分からないこと（隠れた操作・記号と色の意味・規則・キー操作）だけを、1 項目 1 行（70 文字まで・1 節 7 項目まで。`infoSections.test` で検査）で書く。
仕様書 §10 の本文からはこの方針で削った（前の文言は git の履歴にある）。

## §0 ログイン

| 見出し | 本文 |
|---|---|
| WWYD | Hand の Spot（Hero の手番）で、ほかの Player ならどんな Range で打つかを、回答を集めて見る。 |
| ログイン | Google でログインする。表示名とメールアドレスは投稿や回答と一緒には保存しない。 |

## §1 List

| 見出し | 本文 |
|---|---|
| 開く | 未回答は回答へ、回答済みは集計へ。集計は回答するまで見られない。 |
| 削除 | ごみ箱で自分の投稿を削除する（回答も消える。元に戻せない）。 |
| 印 | Reads は Villain の情報、MTT は大会の状況が付いた投稿。 |
| キー（PC） | ↑ ↓（j k）で行を移り、Enter で開く。 |

## §2 Range 入力

| 見出し | 本文 |
|---|---|
| 回答 | Hero の席で、この Spot の Range を塗る。塗らないマスは Range 外。送信は 1 回で、後から変えられない。 |
| SPOT | 卓の SPOT とバーの黄の目盛りが出題の局面。Hero の Hand は回答後に見られる。 |
| 色 | 赤は Fold、シアンは Check・Call、黄は Bet・Raise。 |
| ブラシ | バーの境界をドラッグすると混合（5% 刻み）。同じ頻度のマスを押すと消える。長押しでそのマスの頻度を読み込む。 |
| Size | % は Call した後の Pot に対する割合。 |
| Villain | ◆ の付いた席を押すと投稿者の Read。All Villains で全席、MTT で大会の状況を見る。 |
| キー（PC） | ← → で 1 手、Home で最初、End で Spot。Ctrl+Z・Ctrl+Y で戻す・やり直す。B でブラシ、E で消しゴム。 |

## §3 集計

| 見出し | 本文 |
|---|---|
| 色 | マスの色の割合が回答者の平均の頻度。赤は Fold、シアンは Check・Call、黄は Bet・Raise。 |
| 濃さ | その Hand を Range に入れた回答者の割合。薄いほど少ない。 |
| 白枠 | Hero の実際の Hand。 |
| 自分との差 | 全体との違い（黄が濃いほど違う）。正解・不正解ではない。 |
| SPOT | 卓の SPOT とバーの黄の目盛りが出題の局面。 |
| Villain | ◆ の付いた席を押すと投稿者の Read。All Villains で全席、MTT で大会の状況を見る。 |
| キー（PC） | ← → で 1 手、Home で最初、End で最後。マスにマウスを乗せると内訳（押すと固定）。 |

## §4 Post

| 見出し | 本文 |
|---|---|
| 画像読み込み | T4 の Hand History の画像を端末の中で読み取る。画像は保存も送信もしない。 |
| 投稿できない Hand | Flop 以降に Hero の Action が無い Hand と、Preflop で All-in になった Hand。 |
| Hand | 分かっている Hand だけ入れる（Hero は必須）。入れていない席は Showdown で Muck。 |
| Card キーボード | Q を押したまま上で K・左で T・下で J。♠ を押したまま上で ♥・左で ♦・下で ♣。 |
| 入れ直し | ログの Action や Board の Card を押すとそこから入れ直す。設定・人数・Stack・Hero も後から変えられる。 |
| Villain | 席ごとの Read（任意）。触ると入力、× で未入力に戻る。PFR は VPIP を超えない。Preset は端末だけに保存。 |
| キー（PC） | Card はキーでも打てる（A → s）。Ctrl+Z・Ctrl+Y で Action を戻す・進める。 |

## §4.1 下書き

## §5 アカウント

アカウントメニューを開いている間に ⓘ を押した場合、または規約ページで ⓘ を押した場合に表示する。

| 見出し | 本文 |
|---|---|
| アカウント削除 | 投稿と回答をすべて消す（元に戻せない）。 |
