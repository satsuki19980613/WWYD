# 09 インフォメーションモーダルの文言

仕様書 §5.6・§10 の文言を、画面ごとの確定稿にしたもの。ポーカー用語は英語で書く（2026-09-29。15 章）。画面上に出さない説明・操作方法・記号の意味は、すべてここに集約する。
表示形式は「見出し（dt）＋本文（dd）」の定義リスト。モーダルのタイトルは画面名。閉じるボタンは「閉じる」。

仕様書 §10 の本文をそのまま使い、次の点だけ補った（補った箇所は【補】）。

- ログイン画面の項目（仕様書に画面の定義がないため）【Q-13】
- 色の見分け方（ICMCLEC 踏襲の配色にしたため）【Q-2】

## §1 Spot 一覧（仕様書 §10.1）

| 見出し | 本文 |
|---|---|
| タブ | 「すべて」と「自分の投稿」。 |

## §2 Range 入力（仕様書 §10.2）

| 見出し | 本文 |
|---|---|
| 視点 | Villain（あなた）の席から、Hero の Action に対する Villain の Range を入力する。 |
| Replay | Spot までの Action を再生する。Hero の Hand は回答後に公開される。 |
| Spot の要約【14 章】 | Range の上の行は Board・Hero の Action・Pot。押すと Replay に戻る。 |
| ブラシ | 上部の Action を押すとその Action 100% のブラシになる。バーの境界をドラッグすると混合戦略（5% 刻み）を作れる。マスをタップ、またはなぞるとブラシの頻度で塗られる。 |
| 色【補】 | 赤は Fold、シアンは Check と Call、黄は Bet と Raise。マスの中では左から Fold、Check、Call、Bet・Raise の順に並ぶ。 |
| スポイト | マスを長押しすると、そのマスの頻度をブラシに読み込む。 |
| Range 外 | 塗らないマスは Range 外（この Spot に到達しない Hand）。消しゴムで塗ったマスを Range 外に戻せる。ブラシと同じ頻度のマスをもう一度押しても消える。 |
| 元に戻す・やり直す・クリア | 塗る操作を 1 回ずつ戻せる。なぞった操作は 1 回分として扱う。クリアで全マスを Range 外に戻す。 |
| Size | 33%・50%・75%・125% は Call 後の Pot に対する割合。Raise の場合は現在の Bet 額にその分を足した額が to になる。入力欄とゲージで任意の Size に調整できる。 |
| 下部のバー【14 章】 | Range の大きさ（combos と 1326 combos に対する %）と、Range の中の各 Action の割合。 |
| 送信 | 回答は 1 Spot につき 1 回で、送信後は変更できない。自分の投稿への回答も、他の回答者と同じく全体の集計に含まれる。 |

## §3 集計（仕様書 §10.3）

| 見出し | 本文 |
|---|---|
| 色 | マス内の色の割合が Action 頻度を表す（その Hand を Range 内とした回答者の平均）。赤は Fold、シアンは Check と Call、黄は Bet と Raise。【補：色の対応】 |
| 濃さ | その Hand を Range 内に含めた回答者の割合を 20% ごとの 5 段階で表す。薄いほど Range 外とした回答者が多い。 |
| 白枠 | Villain の実際の Hand。Showdown がない、または Muck の場合は表示されない。 |
| 上部のバー【14 章】 | 全体と自分の Range の大きさ（combos と 1326 combos に対する %）と、Range の中の各 Action の割合。全体は Range 内とした回答者の割合で重み付けしている。 |
| タブ【14 章】 | 全体・自分・自分との差を切り替えられる。マスを選ぶと内訳（全体と自分のバー）が表示される。 |
| 自分との差【14 章】 | 自分と全体の頻度（Range 外を含む）の違いの大きさを黄の濃さで表す。0% は全体と同じ、100% はまったく違う。正解・不正解ではない。 |
| 次の Spot【14 章】 | 未回答の Spot のうち最も新しいものへ進む。 |
| Hand History | Hand を最後まで再生し、Showdown の Hand を確認できる。 |

## §4 Spot 投稿（仕様書 §10.4）

| 見出し | 本文 |
|---|---|
| 画像読み込み | T4 の Hand History 画像を端末内で OCR する。読み取り結果は画像と見比べて直してから反映する。Flop 以降に Hero の Action がない Hand は読み込めない。画像は読み取り後に削除され、保存も送信もされない。 |
| 基本設定 | Cash Game では Ante と Rake を任意で入力する。MTT では Rake は入力できない。Action 入力後は変更できない。 |
| Player と Hand | 最初に人数（2〜6 人）を選ぶ。人数を減らすと早い席から空く（2 人は BTN と BB で、BTN が SB を払う）。分かっている Hand のみ入力する。Hero の Hand は必須。Fold した席でも判明していれば入力できる。Hand 欄を押すと Card キーボードが表示される。 |
| Card キーボード | Q キーはタップで Q、押したまま上で K・左で T・下で J。♠ キーはタップで ♠、上で ♥・左で ♦・下で ♣。C で席の Hand をクリア、⌫ で 1 文字削除。← → で前後の席へ移る。使用済みの Card は入力できない。 |
| Showdown | Hand が入力されていない席は Muck として扱う。 |
| Action 入力 | 額はよく使う額のボタン（Open は bb、3bet・Raise は直前の額の倍率、Flop 以降の Bet は % pot）か、額の欄（スマホは押すと縦のスライダー。なぞって選び、▲▼ で 0.1bb ずつ）で選び、Bet・Raise のボタンで入れる。Fold to・Check to の席を押すと、その席の手番までの Fold・Check をまとめて入れる。その Spot で取れない Action は非活性になる。ボタンの名前は Open・3bet・4bet・Limp など局面に合わせて変わる。Street が終わると Board 入力に進む。↶（1つ戻す）は Action だけを戻し、Board は残る。 |
| 卓とログ【14 章】 | 入力中の Hand を卓に表示する（Hero が手前、手番の席が光る）。卓の Board の Card を押すとその Card 以降を、ログの Action を押すとその Action 以降を入れ直せる。スマホのログは「History」で開く。台の ↶ で 1 つ戻し、↷ で戻した Action を入れ直す。ごみ箱ですべて消す。 |
| Spot | Hero の Flop 以降の Action を 1 つと Villain を 1 つ選ぶ（Preflop は出題できない）。回答対象はその後の Villain の最初の Action。Fold した席も Villain に選べる。 |
| 下書き【14 章】 | 投稿の画面を離れるときに、入力を下書きに保存するか聞く（3 件まで。いっぱいのときはどれかを削除してから保存）。保存した下書きはヘッダーの下書きのボタンから開く。 |

## §4.1 下書き【14 章】

| 見出し | 本文 |
|---|---|
| 下書き | 投稿の入力を 3 件まで、この端末のブラウザに保存できる（ほかの端末とは共有されない）。選ぶと続きから入力できる。下書きから投稿すると、その下書きは消える。 |
