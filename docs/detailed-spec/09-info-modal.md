# 09 インフォメーションモーダルの文言

仕様書 §5.6・§10 の文言を、画面ごとの確定稿にしたもの。画面上に出さない説明・操作方法・記号の意味は、すべてここに集約する。
表示形式は「見出し（dt）＋本文（dd）」の定義リスト。モーダルのタイトルは画面名。閉じるボタンは「閉じる」。

仕様書 §10 の本文をそのまま使い、次の点だけ補った（補った箇所は【補】）。

- ログイン画面の項目（仕様書に画面の定義がないため）【Q-13】
- 色の見分け方（ICMCLEC 踏襲の配色にしたため）【Q-2】

---

## §0 ログイン【補】

| 見出し | 本文 |
|---|---|
| WWYD | ハンドの 1 場面（スポット）で、Villain ならどんなレンジでどう行動するかを、プレイヤーの回答から集合知として見るアプリ。 |

## §1 スポット一覧（仕様書 §10.1）

| 見出し | 本文 |
|---|---|
| タブ | 「すべて」と「自分の投稿」。 |
| フィルタ | スポットのストリート（フロップ〜リバー）で絞り込み、新着順または回答数順に並び替え。 |
| 遷移 | カードを押すと、未回答のスポットは回答画面へ、回答済みのスポットは集計画面へ進む。自分の投稿にも回答でき、集計は回答するまで見られない。 |

## §2 レンジ入力（仕様書 §10.2）

| 見出し | 本文 |
|---|---|
| 視点 | Villain（あなた）の席から、Hero のアクションに対する Villain のレンジを入力する。 |
| リプレイ | スポットまでのアクションを再生する。Hero のハンドは回答後に公開される。 |
| スポットの要約【14 章】 | レンジの上の行はボード・Hero のアクション・ポット。押すとリプレイに戻る。 |
| ブラシ | 上部のアクションを押すとそのアクション 100% のブラシになる。バーの境界をドラッグすると混合戦略（5% 刻み）を作れる。マスをタップ、またはなぞるとブラシの頻度で塗られる。 |
| 色【補】 | 赤はフォールド、シアンはチェックとコール、黄はベットとレイズ。マスの中では左からフォールド、チェック、コール、ベット・レイズの順に並ぶ。 |
| スポイト | マスを長押しすると、そのマスの頻度をブラシに読み込む。 |
| レンジ外 | 塗らないマスはレンジ外（このスポットに到達しないハンド）。消しゴムで塗ったマスをレンジ外に戻せる。ブラシと同じ頻度のマスをもう一度押しても消える。 |
| 元に戻す・やり直す・クリア | 塗る操作を 1 回ずつ戻せる。なぞった操作は 1 回分として扱う。クリアで全マスをレンジ外に戻す。 |
| サイズ | 33%・50%・75%・125% はコール後のポットに対する割合。レイズの場合は現在のベット額にその分を足した額が to になる。入力欄とゲージで任意のサイズに調整できる。 |
| 下部のバー【14 章】 | レンジの大きさ（combos と 1326 combos に対する %）と、レンジの中の各アクションの割合。 |
| 送信 | 回答は 1 スポットにつき 1 回で、送信後は変更できない。自分の投稿への回答も、他の回答者と同じく全体の集計に含まれる。 |

## §3 集計（仕様書 §10.3）

| 見出し | 本文 |
|---|---|
| 色 | マス内の色の割合がアクション頻度を表す（そのハンドをレンジ内とした回答者の平均）。赤はフォールド、シアンはチェックとコール、黄はベットとレイズ。【補：色の対応】 |
| 濃さ | そのハンドをレンジ内に含めた回答者の割合を 20% ごとの 5 段階で表す。薄いほどレンジ外とした回答者が多い。 |
| 白枠 | Villain の実際のハンド。ショーダウンがない、またはマックの場合は表示されない。 |
| 上部のバー【14 章】 | 全体と自分のレンジの大きさ（combos と 1326 combos に対する %）と、レンジの中の各アクションの割合。全体はレンジ内とした回答者の割合で重み付けしている。 |
| タブ【14 章】 | 全体・自分・自分との差を切り替えられる。マスを選ぶと内訳（全体と自分のバー）が表示される。 |
| 自分との差【14 章】 | 自分と全体の頻度（レンジ外を含む）の違いの大きさを黄の濃さで表す。0% は全体と同じ、100% はまったく違う。正解・不正解ではない。 |
| 次のスポット【14 章】 | 未回答のスポットのうち最も新しいものへ進む。 |
| ハンドヒストリー | ハンドを最後まで再生し、ショーダウンのハンドを確認できる。 |

## §4 スポット投稿（仕様書 §10.4）

| 見出し | 本文 |
|---|---|
| 画像読み込み | T4 のハンドヒストリー画像を端末内で OCR する。読み取り結果は画像と見比べて直してから反映する。フロップ以降に Hero のアクションがないハンドは読み込めない。画像は読み取り後に削除され、保存も送信もされない。 |
| 基本設定 | キャッシュゲームではアンティとレーキを任意で入力する。MTT ではレーキは入力できない。アクション入力後は変更できない。 |
| プレイヤーとハンド | 最初に人数（2〜6 人）を選ぶ。人数を減らすと早い席から空く（2 人は BTN と BB で、BTN が SB を払う）。分かっているハンドのみ入力する。Hero のハンドは必須。フォールドした席でも判明していれば入力できる。ハンド欄を押すとカードキーボードが表示される。 |
| カードキーボード | Q キーはタップで Q、押したまま上で K・左で T・下で J。♠ キーはタップで ♠、上で ♥・左で ♦・下で ♣。C で席のハンドをクリア、⌫ で 1 文字削除。← → で前後の席へ移る。使用済みのカードは入力できない。 |
| ショーダウン | ハンドが入力されていない席はマックとして扱う。 |
| アクション入力 | 額はよく使う額のボタン（オープンは bb、3bet・レイズは直前の額の倍率、フロップ以降のベットは % pot）か、額の欄（スマホは押すと縦のスライダー。なぞって選び、▲▼ で 0.1bb ずつ）で選び、ベット・レイズのボタンで入れる。Fold to・Check to の席を押すと、その席の手番までのフォールド・チェックをまとめて入れる。そのスポットで取れないアクションは非活性になる。ボタンの名前はオープン・3bet・4bet・リンプなど局面に合わせて変わる。ストリートが終わるとボード入力に進む。↶（1つ戻す）はアクションだけを戻し、ボードは残る。 |
| 卓とログ【14 章】 | 入力中のハンドを卓に表示する（Hero が手前、手番の席が光る）。卓のボードのカードを押すとそのカード以降を、ログのアクションを押すとそのアクション以降を入れ直せる。スマホのログは「ヒストリー」で開く。台の ↶ で 1 つ戻し、↷ で戻したアクションを入れ直す。ごみ箱ですべて消す。 |
| スポット | Hero のフロップ以降のアクションを 1 つと Villain を 1 つ選ぶ（プリフロップは出題できない）。回答対象はその後の Villain の最初のアクション。フォールドした席も Villain に選べる。 |

## §5 アカウント（仕様書 §10.5）

アカウントメニューを開いている間に ⓘ を押した場合、または規約ページで ⓘ を押した場合に表示する。
