## 5. レビューの要約

  残るのは投稿者の選び方（結果を知ったうえでの Lean、後の Street の General Read。V-026）で、注記で抑えるだけ。自由記述はタイトルだけになった。
- **R-04 コード**: クライアントとサーバーの一致は保たれている。Spot Read の部品に状態の不具合 3 件（V-010〜V-012）。
- **R-05 資料と実装**: ⓘ の「参加した席だけ」（V-015）、定義の不足（V-016）、B-4 の定義文（V-008）ほか。

  `git diff 377b1cb..VR1` の範囲に抜けは無い。
